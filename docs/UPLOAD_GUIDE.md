# GitHub and LinkedIn upload guide

## 1. Create the GitHub repository

Recommended repository name:

```text
qgss-2026-quantum-lab-portfolio
```

Recommended description:

```text
Sanitised QGSS 2026 lab portfolio covering Qiskit patterns, hardware-aware circuits, noise, error mitigation, QAOA and sample-based quantum diagonalisation.
```

Suggested GitHub topics:

```text
qiskit quantum-computing ibm-quantum quantum-chemistry qaoa error-mitigation python jupyter-notebook
```

Upload the **contents** of this folder so that `README.md` is at the repository root. Before publishing, open the notebooks on GitHub and verify that placeholders such as `<YOUR_JOB_ID>` appear instead of real values.

## 2. Add it to LinkedIn

1. Publish the text in `linkedin/LINKEDIN_POST.md`.
2. Attach `media/QGSS2026_LinkedIn_Cover.png` and up to three individual lab images.
3. Add the GitHub link to the post.
4. Add the project to **Profile → Add profile section → Recommended → Add projects** using `LINKEDIN_PROJECT_ENTRY.md`.
5. Add the repository to the **Featured** section of your profile.

## 3. Recommended post images

- Cover collage
- Lab 1 reduced-depth GHZ circuit
- Lab 2 backend benchmark
- Lab 4c SQD convergence result

## 4. Final safety check

Never publish:

- IBM Quantum tokens or API keys
- IBM Cloud CRNs or service-instance identifiers
- Runtime job IDs
- personal email addresses or telephone numbers
- local filesystem paths
- screenshots showing account settings or credentials
